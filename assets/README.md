# Assets Folder

This folder should contain your app's assets:

## Required files for production:

- **icon.png** - 1024x1024px app icon
- **splash.png** - Splash screen image (recommended: 1284x2778px)
- **adaptive-icon.png** - 1024x1024px Android adaptive icon (foreground)
- **favicon.png** - 48x48px favicon for web

## Temporary Placeholders:

For development, Expo will use default assets if these files are missing.

To generate proper assets, you can use tools like:
- [Figma](https://figma.com)
- [Canva](https://canva.com)
- [App Icon Generator](https://www.appicon.co/)

## Note:

Replace the placeholder files with your actual branding before deploying to production.
